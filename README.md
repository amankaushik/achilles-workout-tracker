# Achilles Workout Tracker

A modern, progressive workout tracking application designed to help you follow and monitor your strength training programs with precision.

🔗 **Live Demo:** [https://workout.materialpacman.com/](https://workout.materialpacman.com/)

## Overview

Achilles Workout Tracker is a comprehensive fitness application that enables users to track their workout progress, view detailed statistics, and manage multiple training sessions. Built with a focus on user experience and data-driven insights, it provides an intuitive interface for logging exercises, monitoring performance trends, and maintaining workout consistency.

## Key Features

- **Workout Tracking**: Log sets, reps, and weights for each exercise with an easy-to-use interface
- **Multiple Programs**: Support for different training programs with structured phases and weeks
- **Session Management**: Create and manage multiple training sessions simultaneously
- **Workout History**: View past workouts with detailed exercise logs and completion timestamps
- **Advanced Statistics**:
  - Exercise progression charts and trends
  - Weekly workout frequency analysis
  - Personal records and performance metrics
  - Activity calendar with workout intensity visualization
- **Mobile Responsive**: Fully optimized for mobile and desktop use
- **Data Persistence**: Secure cloud storage with Supabase backend

## Tech Stack

- **Frontend**: React 18, TypeScript
- **Build Tool**: Vite
- **Backend**: Supabase (PostgreSQL, Authentication)
- **Charts**: Recharts
- **Icons**: Lucide React
- **Styling**: Custom CSS with CSS Variables

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
